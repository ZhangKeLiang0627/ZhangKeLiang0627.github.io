写在前面

生活的锚点…

我还觉着这回杂记怎么着都要停更了，结果还是回来接着写（呵…

趟在这片没有一丝生机的汪洋内，没有海浪声、没有鸟鸣声、没有风声，我什么都听不见，就连心跳，和此刻浮沉的躯壳也无法感受。但是我能看到，清晰的看到，我在一点点被消耗、被簇拥而上的鱼群蚕食、苦涩的盐水腐蚀着我的生命。此刻，苦苦哀求，我不求自己能够避免多少折磨的痛楚，至少一点点陪伴和安慰请给我吧…至少在彻底结束前，让我记住施恶者丑恶的嘴脸。我好想逃跑啊——这种极其诡异的感受，入侵生活的各个角落，在任何时间里都有充分的理由跳出来给你一个亲密的Jump scare.

最近有尝试使用ai来写写文章，发现在一些功能性的文字上面，ai的表现还是挺不错的，比如几个礼拜前让ai简单梳理一个「被动裁员、主动离职需要知道的一些事」就表现的很棒，内容输出也比较清晰，和在小某书上面搜到的内容大差不差的。但一旦来到非常带有个人风格和情绪的文章，或者非常私人的日记类文字的时候，ai反而就变的非常的机械、无措，变的非常的“假”，我尝试让它去学习了我过往的所有杂记，ai居然能够把“阿公”错认为是我的父亲，果然，它明显不懂我也不是我，我当机立断，没再浪费我的token（笑、、、

所以呢，说回来，本来以为没什么好写了、也没有什么时间写了，所以契机是？

乙型流感。

对的，很不幸运的，在八月底最后这几天，一个不小心我也被传染了流感，喜提两天病假，也是过上好日子了，上三休四。可乙流也忒不好受，高烧反复，退烧还难，前前后后折腾了三天，终于在第四天稍微感觉身体的掌控权又重新捏到自己的手里，非常的不容易呀。然后这里面也是有些有趣的事情可说的：

乙流第一天上午，高烧浑身酸痛，提前闹钟响早早就痛醒，心大喊不好，果断请假。外卖买了些感冒药。上午吃了一粒感康，吃了饭就昏睡过去。下午醒来，泡了感冒灵，喝完一量体温39.1，于是又一颗布洛芬下肚。然后继续昏睡，到傍晚醒来，发现没有退烧啊，没有退烧啊，这不对劲呀。去小某书查资料，震惊！感冒药和退烧药不可混吃，会导致肝肾衰竭！我心想完蛋了，kkl啊，没有见识还没有常识，我不会要死了吧。连忙上急诊…一通核酸抽血化验下来，确诊乙型流感，医生还纳闷我说：你吃布洛芬没有作用？不会和感冒灵有药理反应吧，还好你吃的不多，没什么事，下次吃药之前要注意看一下啊年轻人！

医生叮嘱我得了这个流感要做好拉锯战的准备，多喝水多休息，高烧肯定是会反复的，最快也要三天，一整个就是，加油年轻人我看好你的仗势。从医院回来高烧仍然不下，于是想吃颗布洛芬，然后就去睡觉吧。吃之前又想到为什么布洛芬退烧没效果了呢，翻了翻外包装，好家伙，怪不得没效呢，已经过期两年多了…kkl啊，你真是心大啊我跳，寻思你直接食物中毒发烧吃的也是这个过期布洛芬是纯硬抗啊。

空调滚滚不停的三伏天，一只介于青年和中年之间的鼠，又多了一段寒颤的经历（指病的发抖。好在，和病魔斗智斗勇折腾了这三天，除了发烧和头疼，没有什么非常严重的症状，也算是好事。只不过，八月初的时候才挺过一次普通的病毒感冒，没想到八月底又来，估计受多两趟我的血液里面要流淌着一股百毒不侵的神性了。

好了，那为了庆祝我死里逃生大病初愈，让我们，干杯吧（笑。

2026/8/14 - 冒烟的灯泡

何为完美的一天？

愈发觉得工作上对身体的消耗之大，就像个无底洞。但明明这快一个多月我尽可能把除工作时间以外的所有时刻都归还到它本应该属于的时间，但是还是没有找到一个完美的平衡点。外表看去，依旧像是一颗冒烟的灯泡。

周五下班久违的和圆约出来吃顿饭看电影，自从上次看给阿嬷的情书，我们大约一个多月没有见过面了。依然是那样，为了赶电影开映时间，我们匆忙的吃饭，但是也终于吃到了潮发（打破了我们5次没有吃上的超长记录！

我和他吐槽又有多少多少好同事逐一离职、+1是多么多么的坏、吐槽现在的工作有多么的无聊、多么没有意义的死撑。但我却从来没有做好跳出去的准备。圆问我，你还在等什么啊，现在就是好时机呀，准备准备就去dji试试嘛。我总是说还没准备好…没准备好，还是害怕？

每回和圆出来，总是能够给予我第一线的ai资讯和启发，聊着聊着总能绕回去ai相关的话题，还记得上一次过年的时候才从它的口中第一次知道了OpenClaw，今天好不容易把MCP和Skill玩的比较好了，才发现外面全部都是harness agent了，用圆的话说，你至少比我们落后了大半年啊。我只能，震惊，并且苦笑（然后回来狠狠入坑harness、、、

这次看的电影是沈腾的「欢迎来龙餐馆」，非常的好啊，我和圆从电影院出来就不言而喻开始笑，又到了传统的打分环节，我们给它打了9分，但是排名的话最后还是和阿嬷情书并列第一，因为题材关系真的不想拿出来比，但是如果非要比较，我和圆还是一致认为阿嬷更加出色一点，感情戏和剧本打磨的太好的实在，而且成本低，没大咖，却热烈真挚。

还做了些什么呢？月初的时候，再次迎来张泽的巡回livehouse，听了场不错的show（他们老是喜欢在中午一点半的时候开场，真是有够燥的，数一数，这是第三年了啊…

然后再说说上个月坐别人的电鸡上下班下车的时候摔跤的事情，连续两次都是我的直筒裤裤腿钩住了车的脚架，然后没注意人之间跨越下车，然后失去平衡直接扑通倒地，好在我比较难杀没有到受什么伤，反而是失去了一块陪伴我两年多的miband，和勾烂了一条裤子（btw仍然在服役当中haha~

上个月也再次和大学实验室的小伙伴聚餐了一回，终于是见到他们口中的牢大，果然足够商务风趣哈，一起度过了愉快的时光！

and，好像再没有什么值得提起或者记下的事情了，或是当下忘记了，稍微有些唏嘘，写不下去了:(

2026/8/29 - 替它紧张

galánday啊！！！

w我的天空许久不明亮了好像被遮住，呼吸变得缓慢，思绪繁杂，昏昏沉沉的只想陷入睡眠。太阳已经很久没有出现了…

galánday是专辑励志论里面小队长自创的一个词语，意思是「美好的一天」，嘎懒day嘎懒day、、、说起来，美好的一天，往往伴随着一个好消息和一个坏消息，烂梗:)

好消息是，之前提到很多次的裁员，大概从五六月份就隐隐有迹象要动手，一直等啊等啊，到今天终于是等到了刀子落下，我们公司最终也像其他BU一样没有顶住压力，开始裁员了；而坏消息是，裁员名单上没有我的名字，这就很难受了，我们裁员方案是按照每个部门团队的人数比例，对半砍，按照贡献值依次排列，然后低于50%的人拦腰砍断…结果没有想到，本来是要解放的时候了，还他妈的居然放我留下来，我，一个应届生，什么也不懂的卡拉米。现在全公司应该就剩下我一位应届进来的buddy了吧。看着身边一个个熟悉的面孔收拾东西当天签字当天走，都不带一丝挽留的，第二天发现身边的座位都空落落的，真是唏嘘呵。

当即我就和+1说要下一波裁员名单的份额，不管有没有吧，我都要走（但是大概率应该还会继续裁，只不是早死晚死而已。

…

真是可笑至极，今天已经是遭受裁员风波的第二个周，不出所料的办公区一片荒凉，静谧，呵。昔日摆满显示器、键盘、产品的同事办公位置上空落落的，剩下的只有灰尘印在桦木色的桌和纸屑，仿佛许久都不曾有人坐过一样。这班是不可能再继续上了，我到每位离职同事的位置上都坐了一会儿，什么也没想净是盯着眼前的空气发呆，麻木旋即便成一股涌上心头的莫名火，去他妈的需求排期、去他妈的产品故事、去他妈的傻逼领导，一切都无意义了…我扫视一周，搜索中多数都是灰色的眼神，其他留下来的同事们也抱有相同的想法罢？

我也是真他妈的贱，公司都成这样了，有礼包名额也不早早争取，结果刀子落下来，留下来擦屁股的人往往是从前最卖力干活最玩命加班的那群人，始终没有改变过，公平在哪里？也不用再谈。这种裁员本来就是鱼死网破的利益之争，谁都想保住自己的那份…救命稻草。

裁员后为了稳固军心，随后的第一个组内会议，竟然是叫我们剩下的人好好干，语气之霸道，好像是在说，你们所有人，离开了这，就永远找不到这么好的工作了，要学会珍惜，要感恩公司赐予你们能够继续工作的位置…横竖没听，我一直在玩手机，听说我们部门的裁员结束了隔壁的部门是这周才开始，没有人能够逃掉，下午公司楼下多了好多人买咖啡，趁着等咖啡、抽烟的间隙，围成一圈又一圈：诶，你们部门走多少人？你在名单里不？下一份工作做啥，还是行业内不？

话题额外的一致。我想吧，这公司玩完了，彻底完了。

还在谈话中意外得知，负责我们组的HR在排完大礼包以后上周五也lastday，新的HR、新的白手套晚点会切入进来继续后续的礼包派发。嚓，圣诞老人派完礼物也会收到自己的礼物吗？我还没上车啊啊啊啊啊啊啊，救命。

+1在群里大放厥词，你们还有谁我能够指挥的动的，举个爪。无人回应。于是土皇帝开始暴论，如果没人能够指挥的动我自己走，如果不想干了，这两天你们一起毕业别干了！求之不得啊，过了会儿估计某人觉得自己这句话不太妥人都走了谁给我干活啊于是又撤回了，重新发了一句：所有人，想要继续干的+1，不想干的-1…没人惯着他，全员-1，“只有+1在+1”。这张聊天截图，估计现在已经传遍整个公司了，可惜，再也没有裁员名额，我们似乎只能干到死、或者自离（真是搞笑，一手好牌，结果没有任何人会打，甚至于乱打。

摆烂吧，我只能想到的操作就是摆烂了，工资照拿，包装一下简历，出去面试，面到合适面到爽就走，反正又不裁我，裁我那就拿礼包走人，我怎么都不亏啊。趁着这两天，啥代码也没写，也没有人管，项目经理像死了一样，人影都找不到或者裁光了，我转遍了整个公司的工位，把过去一年多以来所有认识的不认识的、合作的没合作过的人的wx全加了个遍，哈哈，没事就下楼买个咖啡，走走逛逛，一天也就这么结束了。我能想到的办法就是这么耗着，绝对没有意义，但是恶心人的方式，耗着！

原本计划在七月份就更新的简历，次次想要下定决心的时候，项目总是给出一点希望转机，让人想要再努力一把，一天天，没有例外总会回到绝望，泡沫，包括我在内的所有人对于这些产品的态度，由坚定到吃力到失望到麻木。这两个月似乎大家都像是坐上了失控的旋转木马，无法停歇。以至于我回过神来的时候，甚至会诧异自己竟然在深夜的阳台里疯狂抽烟，真他妈傻逼，明明学生时期还大肆写wb抨击二手烟，自己倒是不知不觉抽起来了呵。kkl压力又能有多大呢？这才是工作的第一年呢，后面还有许许多多的漫漫长的时间，要度过和今天这样臭屁的时光，遇到傻逼的同事和领导，干倒更多的企业，再多拿几次赔偿大礼包，工作生涯也就算圆满了吧？
